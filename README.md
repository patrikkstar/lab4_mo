# Теоретические сведения

## Функция активации BReLU

В скрытом слое использовалась функция активации BReLU:
$$
BReLU(x)=
\begin{cases}
0, & x \le 0 \
x, & 0 < x < 1 \
1, & x \ge 1
\end{cases}
$$

Данная функция ограничивает значения диапазоном от 0 до 1 и позволяет сохранять нелинейность модели.



## Функция активации Sigmoid

Для выходного слоя использовалась функция Sigmoid:

$$
\sigma(x)=\frac{1}{1+e^{-x}}
$$

Результатом работы функции является значение из интервала $[0;1]$, которое интерпретируется как вероятность принадлежности объекта к положительному классу.


## Функция потерь Cross-Entropy

Для обучения нейронной сети использовалась бинарная кросс-энтропия:

$$
L = -\frac{1}{N}
\sum_{i=1}^{N}
\left[
y_i \log(\hat y_i)
+
(1-y_i)\log(1-\hat y_i)
\right]
$$

где:

* $y_i$ — истинная метка класса
* $\hat y_i$ — предсказанная вероятность
* $N$ — размер выборки



## Алгоритм SGD

Стохастический градиентный спуск обновляет параметры модели по правилу

$$
\theta = \theta - \eta \nabla L
$$

где:

* $\theta$ — параметры модели
* $\eta$ — скорость обучения
* $\nabla L$ — градиент функции потерь



## Алгоритм Adam

Алгоритм Adam объединяет Momentum и RMSProp.

Алгоритм позволяет

* автоматически адаптировать шаа обучения
* имеет более быструю сходимость
* устойчивость к шумным градиентам

# Архитектура моделей

## Однослойная нейронная сеть

Однослойная сеть имеет следующую структуру:

$$
z = XW+b
$$

$$
\hat y = \sigma(z)
$$

Модель содержит только выходной слой и способна строить линейную границу решений.


## Перцептрон с одним скрытым слоем

Структура модели:

$$
H=BReLU(XW_1+b_1)
$$

$$
\hat y=\sigma(HW_2+b_2)
$$

Наличие скрытого слоя позволяет строить нелинейные разделяющие поверхности.

# Анализ результатов

Для датасета make_moons лучшей оказалась сеть с одним скрытым слоем. Значение F1-score на тестовой выборке составило 0.9620 против 0.8684 у однослойной сети.
Это связано с тем, что задача требует построения нелинейной границы решений. Однослойная сеть способна строить только линейные разделяющие поверхности, а наличие скрытого слоя позволяет корректно описывать сложную структуру данных.
Для датасета make_classification более высокие результаты показала однослойная сеть. Значение F1-score составило 0.9744 против 0.9189 у сети со скрытым слоем.
Возможно, структура данного набора данных оказалась достаточно простой для линейного разделения, поэтому дополнительный скрытый слой не дал преимуществ и привел к небольшому ухудшению обобщающей способности модели.
На обоих наборах данных алгоритм Adam показал высокую эффективность и обеспечил быструю сходимость процесса обучения.
